# 🩺 Kahoot Medicina Forense

Examen interactivo estilo Kahoot con **30 preguntas** de medicina forense.

## 📚 Temas

- **Atropellamiento** (12 preguntas)
- **Exploración ginecológica** (12 preguntas)
- **Exploración proctológica** (6 preguntas)

## ⚙️ Características

- ⏱️ 15 segundos por pregunta
- ⭐ Puntuación basada en velocidad (hasta 1000 pts por pregunta)
- 🔁 Opción de reintentar las preguntas falladas al final
- 🎨 Diseño tipo Kahoot (fondo morado, botones rojo/azul/amarillo/verde)
- 📱 100% responsive para celular
- 🏆 Pantalla final con precisión, tiempo promedio y repaso de errores

## 🎮 Cómo jugar

Abre el archivo `index.html` en cualquier navegador, o visita la versión publicada en GitHub Pages.

## 🚀 Publicar en GitHub Pages

1. En este repo → **Settings** → **Pages**
2. En "Source" elige **Deploy from a branch**
3. Rama: `main`, carpeta: `/ (root)`
4. Save → espera 1-2 min
5. El link queda en `https://carlossbel.github.io/Kahoot-Forense/`
